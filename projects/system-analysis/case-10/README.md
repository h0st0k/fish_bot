# 🎯 Кейс №10 — Проектирование верхнего уровня требований

## 1. Декомпозиция целей (Иерархия по GQM / Goal Question Metric)

### 1.1. Бизнес-цель (Goal)
* **Цель:** Повысить операционную эффективность и прозрачность контроля парка из 200 велосипедов для технической службы.
* **Метрика успеха:** Сокращение времени простоя неисправного транспорта на станциях с 14 часов до <2 часов.

### 1.2. Аналитические вопросы (Questions)
1. Как оперативно выявлять велосипеды с критическим уровнем заряда аккумулятора электронного замка (<15%)?
2. Каким образом автоматизировать распределение заявок на ремонт между выездными техниками?
3. Как минимизировать человеческий фактор при фиксации факта выполненного техобслуживания?

### 1.3. Информационные требования (Metrics / Требования к данным)
* **М-01:** Мониторинг логов заряда батареи каждого устройства в режиме реального времени.
* **М-02:** Снятие GPS-координат принудительно заблокированных или оставленных вне станций велосипедов.
* **М-03:** Учет нормативного времени (SLA) закрытия инцидента техником с момента назначения заявки.

## 2. Модели поведения (Behavioral Models)

### 2.1. Сценарий: Реагирование системы на критический заряд батареи (Диаграмма состояний)
```text
[Статус: Свободен (Заряд > 20%)] 
       │
       ▼ (Снижение заряда до 15%)
[Статус: Сервисное предупреждение] ── (Авто-создание таски для техника)
       │
       ▼ (Снижение заряда до 5%)
[Статус: Заблокирован для аренды] ── (Скрытие маркера с карты клиентов)
       │
       ▼ (Техник заменил аккумулятор)
[Статус: Свободен (Заряд 100%)]
```

### 2.2. Матрица переходов состояний сущности «Заявка на ремонт» (Task Lifecycle)

| Текущее состояние | Триггер (Событие) | Целевое состояние | Системное действие |
| :--- | :--- | :--- | :--- |
| **Не назначена** | Сбой телеметрии от IoT | **Новая** | Поиск ближайшего техника по GPS, генерация Task ID |
| **Новая** | Нажатие «Принять» в приложении техника | **В работе** | Блокировка заявки для других сотрудников, запуск таймера SLA |
| **В работе** | Сканирование QR-кода на байке | **Проверка** | Валидация: тот ли велосипед ремонтируется |
| **Проверка** | Нажатие «Готово» + фото замка | **Выполнена** | Списание задачи, отправка команды разблокировки на замок |

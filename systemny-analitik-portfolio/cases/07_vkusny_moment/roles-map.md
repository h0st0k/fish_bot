## 🔒 3. Матрица управления доступом RBAC (Role-Based Access Control)

Для защиты персональных данных (152-ФЗ) и бизнес-логики сервиса доставки еды, системным аналитиком спроектирована ролевая матрица доступа к CRUD-операциям над ресурсами бэкенда:

| Ресурс (Объект) | Метод API / Действие | Роль: Клиент | Роль: Администратор кухни | Роль: Курьер |
| :--- | :--- | :---: | :---: | :---: |
| **Профиль (ПДн)** | `GET /profiles/{id}` | **Разрешено** *(только свой)* | **Запрещено** | **Запрещено** |
| **Меню блюд** | `GET /menu`, `POST /menu` | **Только чтение (GET)** | **Полный доступ (CRUD)** | **Только чтение (GET)** |
| **Заказ (Order)** | `POST /orders` (Создание) | **Разрешено** | **Запрещено** | **Запрещено** |
| **Статус Заказа** | `PATCH /orders/{id}/status` | **Запрещено** | **Разрешено** *(«Готовится», «Готов»)* | **Разрешено** *(«Доставлен»)* |
| **Геопозиция** | `POST /couriers/geo` | **Запрещено** | **Только чтение (GET)** | **Разрешено** *(отправка координат)* |
| **Аналитика** | `GET /reports/financial` | **Запрещено** | **Запрещено** | **Запрещено** |

*Примечание по ИБ: Полный доступ к финансовой аналитике и экспорту отчетов имеет исключительно скрытая роль «Руководитель бизнеса», запросы от других ролей блокируются на уровне API Gateway с кодом ответа `403 Forbidden`.*

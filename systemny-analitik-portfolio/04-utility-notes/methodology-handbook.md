# Справочник Системного Аналитика: Инженерия требований и ИБ

## 1. С сквозная трассировка рабочей среды (По Адаму Накостоеву) [01-127]
*   **Jira / Kaiten:** Фиксация бэклога. Описывает **ЧТО** нужно сделать (задачи, эпики, User Stories, Acceptance Criteria) [01-121, 01-125, 01-127].
*   **Confluence / Вики:** Хранение спецификаций. Описывает **КАК** это должно технически работать (SRS, Use Cases, макеты) [01-122, 01-125, 01-127].
*   **Swagger / OpenAPI:** Интерактивная витрина REST-эндпоинтов, структур JSON-запросов (`Request`) и статус-кодов ответов (`Response`) [01-124, 01-127].
*   **Postman:** Инструмент отправки ручных запросов для проведения авторской приемки фич у бэкенд-разработки [01-127].
*   **DBeaver:** Проводник к реляционным базам данных (PostgreSQL) для составления SQL-скриптов (`SELECT`, `JOIN`, `GROUP BY`) при валидации качества данных [01-125, 01-127].

## 2. Технология интервьюирования и Трехцветный метод анализа MoM
После завершения интервью сырой текст протокола встречи (Minutes of Meeting / MoM) размечается аналитиком тремя маркерами для формирования чистого бэклога задач:
*   <span style="color:green">**Зеленый маркер — Факты и требования:**</span> зафиксированные бизнес-правила и жесткие рамки системы (готовые вводные для ТЗ).
*   <span style="color:orange">**Желтый маркер — Неопределенности:**</span> размытые места, требующие технического или продуктового уточнения на следующем созвоне.
*   <span style="color:red">**Красный маркер — Противоречия:**</span> логические нестыковки, когда стейкхолдеры заявляют противоположные вещи. Требуют жесткой фасилитации.

## 3. Нормативный контур ИБ и персональных данных (По Я. С. Гродзенскому)
При проектировании нефункциональных требований (NFR) к безопасности систем аналитик оперирует базовыми стандартами регуляторов РФ:
*   **ИСПДн** — Информационная система персональных данных: комплекс средств автоматизации, подлежащий обязательной защите и сертификации по требованиям Федерального закона № 152-ФЗ «О персональных данных».
*   **ФСТЭК** — Федеральная служба по техническому и экспортному контролю: ключевой государственный орган-регулятор в области технической защиты конфиденциальной информации и КИИ (Критической информационной инфраструктуры).
*   **СКЗИ / СКЗИ** — Средства криптографической защиты информации: математические программно-аппаратные инструменты шифрования данных и построения защищенных VPN-каналов.

# Кейс 09 — Шеринг велосипедов «Прокачу»

**Описание:**  
Стартап первого сезона с амбициями масштабирования — от Telegram-бота к полноценному мобильному приложению. Кейс охватывает реальные боли пользователей, технические ограничения и бизнес-требования для разработки продукта с нуля.

## 🎯 Ключевые требования

### Функциональные требования (FR)

| ID | Требование |
|----|------------|
| FR-01 | Система должна регистрировать пользователей по номеру телефона и email |
| FR-02 | Система должна отображать интерактивную карту с пинами станций проката |
| FR-03 | Система должна обеспечивать удалённое бронирование велосипеда на 15 минут |
| FR-04 | Система должна автоматически завершать сессию аренды на основе геолокации |
| FR-05 | Система должна предоставлять интерфейс для отправки отчёта о поломке |
| FR-06 | Система должна предоставлять доступ к истории поездок |
| FR-07 | Стоимость проката: 150 руб/час, 800 руб/сутки |

### Нефункциональные требования (NFR)

| ID | Требование |
|----|------------|
| NFR-01 | Приложение доступно на iOS (15.0+) и Android (10.0+) |
| NFR-02 | Время обработки запроса — не более 1.2 секунды при 95-м перцентиле |
| NFR-03 | Нагрузка — до 300 активных сессий в пиковые часы |
| NFR-04 | Интеграция с платёжным шлюзом по стандарту PCI DSS |
| NFR-05 | Бюджет — не более 2 000 000 рублей |
| NFR-06 | Срок реализации — 3 месяца |

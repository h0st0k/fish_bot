# 📋 Артефакт: Acceptance Criteria (Критерии приёмки)

Конкретные и измеримые условия проверки требований для User Story «Оформление заказа».

* **AC-01 (Форма оформления):** Система показывает форму: адрес, телефон, способ оплаты, комментарий (необязательно), сдача с суммы.
* **AC-02 (Валидация телефона):** Поле «Телефон» обязательное. Проверка: 11 цифр, начинается с +7 или 8.
* **AC-03 (Валидация адреса):** Поле «Адрес» обязательное. Минимум 10 символов.
* **AC-04 (Способы оплаты):** Карта онлайн или наличные при получении. Если наличные — появляется поле «Приготовить сдачу с».
* **AC-05 (Пустая корзина):** Если корзина пуста — кнопка «Оформить» неактивна, подсказка: «Добавьте блюда в корзину».
* **AC-06 (Успешное оформление):** После оформления система показывает номер заказа и расчётное время доставки (текущее время + 60 минут).
* **AC-07 (Ошибка сервера):** Если сервер не отвечает — сообщение «Не удалось оформить заказ. Попробуйте позже» и кнопка «Повторить».
* **AC-08 (Зона доставки):** Система проверяет адрес в зоне доставки. Если не в зоне — «Доставка в этот район не осуществляется».

# 👥 Артефакт: User Stories (Проектирование от ценности)

В соответствии с методологией, каждая история строго отвечает на три вопроса: Роль, Действие и Измеримая бизнес-ценность («Зачем?»).

### 👤 Роль: Клиент
1. **Просмотр меню:** Я как клиент, хочу просматривать меню с фото, ценами и описанием, чтобы выбрать, что заказать.
2. **Работа с корзиной:** Я как клиент, хочу добавлять блюда в корзину и менять количество, чтобы собрать заказ перед оформлением.
3. **Оформление заказа:** Я как клиент, хочу оформить заказ: указать адрес, телефон, способ оплаты, чтобы получить доставку.
4. **Отслеживание статуса:** Я как клиент, хочу отслеживать статус заказа, чтобы знать, когда привезут.
5. **История заказов:** Я как клиент, хочу видеть историю заказов и повторять прошлый заказ, чтобы не собирать его заново.

### 🔧 Роль: Администратор
6. **Управление заказами:** Я как администратор, хочу видеть список заказов и менять их статус, чтобы управлять процессом доставки.

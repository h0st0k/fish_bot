# 🔀 Артефакт: Use Case (Сценарий взаимодействия)

**Название:** Оформление заказа  
**Актор:** Клиент  
**Предусловие:** Клиент авторизован, корзина не пуста, приложение открыто.

### 🔄 Основной поток (Happy Path)
1. Клиент нажимает «Оформить заказ» в корзине.
2. Система показывает форму ввода: адрес доставки, телефон, способ оплаты, комментарий.
3. Клиент заполняет адрес и телефон.
4. Клиент выбирает способ оплаты.
5. Клиент нажимает «Заказать».
6. Система проверяет адрес на вхождение в зону доставки.
7. Система создаёт заказ в БД, присваивает номер и рассчитывает время доставки.
8. Система показывает экран подтверждения: номер заказа, время доставки, статус «Принят».

### 🔁 Альтернативные и ошибочные потоки
* **4a. Оплата наличными:** Клиент выбирает «Наличные». Система показывает поле «Приготовить сдачу с». Клиент указывает сумму. Возврат на шаг 5.
* **3a. Телефон не заполнен:** Система подсвечивает поле красным: «Обязательное поле».
* **3b. Короткий номер:** Телефон менее 11 цифр: «Введите номер полностью».
* **6a. Вне зоны доставки:** Выводится сообщение: «Доставка в этот район не осуществляется».
* **6b. Сервер не отвечает:** Ожидание более 10 сек — «Не удалось оформить. Попробуйте позже» + кнопка «Повторить».

**Постусловие:** Заказ успешно создан и передан в панель администратора.

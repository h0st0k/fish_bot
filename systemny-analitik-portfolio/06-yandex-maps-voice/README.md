## 👥 1. Пользовательские истории (User Stories)

# Требования к голосовому ведению в Яндекс.Картах

## Функциональные требования (FR)

| ID | Требование |
|----|------------|
| FR-01 | Система должна поддерживать построение маршрутов для велосипедов и самокатов |
| FR-02 | Маршрут должен автоматически исключать лестницы и строить по велодорожкам |
| FR-03 | Голосовые подсказки должны активироваться при начале движения по маршруту |
| FR-04 | Алиса должна озвучивать: направление поворота, расстояние до манёвра, оставшееся время |
| FR-05 | Подсказки должны работать в фоновом режиме при свёрнутом приложении |
| FR-06 | Система должна пересчитывать время прибытия при изменении скорости |
| FR-07 | Пользователь может отключить голосовое ведение в любой момент |

## Нефункциональные требования (NFR)

| ID | Требование |
|----|------------|
| NFR-01 | Задержка между сменой позиции и голосовой подсказкой не должна превышать 1 секунду |
| NFR-02 | Приложение должно поддерживать 25 млн активных пользователей без деградации |
| NFR-03 | Фоновый режим не должен разряжать батарею более чем на 10% за час |
| NFR-04 | Голосовые подсказки должны быть понятны даже при внешнем шуме (ветер, город) |

## 🎯 4. Критерии приёмки (Acceptance Criteria)

# API-контракт: Голосовое ведение

## GET /route
**Описание:** Получить маршрут для велосипеда/самоката

**Параметры:**
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| start_lat | float | да | Широта начальной точки |
| start_lon | float | да | Долгота начальной точки |
| end_lat | float | да | Широта конечной точки |
| end_lon | float | да | Долгота конечной точки |
| type | string | да | transport (bike / scooter) |

**Ответ (200 OK):**
{
  "route_id": "abc123",
  "distance_m": 3500,
  "duration_sec": 900,
  "steps": [
    {
      "action": "turn_right",
      "distance_m": 200,
      "instruction": "Поверните направо на ул. Ленина"
    }
  ]
}
{
  "user_id": "user_456",
  "instruction": "Через 200 метров поверните направо",
  "priority": "high"
}
{
  "status": "sent",
  "timestamp": "2026-06-23T15:30:00Z"
}

## 🧪 6. Тестирование

# Бизнес-правила

| № | Правило |
|---|---------|
| 1 | Голосовое ведение включается только при выборе вело/самокатного маршрута |
| 2 | Если маршрут короче 500 метров — голос не включается |
| 3 | В ночное время (23:00–06:00) голосовые подсказки тише на 30% |
| 4 | При повторном прохождении маршрута голос адаптируется (реже подсказывает) |
| 5 | Фоновый режим работает только при активном GPS-трекинге |
| 6 | Если пользователь остановился > 2 минут, система спрашивает: "Продолжаем маршрут?"

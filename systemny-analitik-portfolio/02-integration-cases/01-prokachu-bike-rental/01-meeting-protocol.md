# Протокол рабочей встречи с заказчиком (Сервис «Прокачу»)

**Дата:** 15.07.2026 | **Участники:** СА (Павлов Д.В.), Руководитель, СТО (Дмитрий), Оператор (Анна) [01-54].  

## Ключевые тезисы:
*   Текущий Telegram-бот неудобен (8 шагов для аренды), нет карты (выводится плоский список улиц), завершение только вручную текстовой командой [01-54].
*   Анна фиксирует 132 жалобы за месяц. Критические боли — недошедшие коды СМС для открытия замков (38 тикетов) и лишние списания, когда клиенты забывают закрыть аренду (27 тикетов) [01-54, 01-55].
*   СТО Дмитрий устанавливает жесткие ограничения: бюджет 2 млн рублей, срок 3 месяца, нативные приложения iOS/Android, безопасность транзакций строго по международному стандарту PCI DSS [01-54].

## Договорённости:
1. Выпустить мобильное приложение (iOS + Android) с интерактивной картой станций проката [01-54].
2. Реализовать 15-минутную бронь с пуш-таймером обратного отсчета [01-54].
3. Внедрить автозавершение аренды по геолокации (геофенсинг) для защиты от забывчивости клиентов [01-54].
4. Заменить отправку СМС-кодов на прямое управление замком со смартфона через Bluetooth (BLE) [01-54, 01-55].

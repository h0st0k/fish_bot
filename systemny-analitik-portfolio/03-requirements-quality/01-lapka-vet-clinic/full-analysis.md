# Анализ требований и проектирование с нуля: Ветклиника «Лапка»

## 1. Выявление скрытых условий (Вопросы «А что, если...»)
1.  *А что, если к моменту визита владельца нужный врач экстренно ушел на больничный или уехал на операцию?* (Система должна зафиксировать инцидент, запустить сценарий оповещения и предложить клиенту автоматический перенос сессии).
2.  *А что, если администратор вручную поставил операцию посреди дня во внутреннюю CRM?* (МИС должна по API мгновенно передать событие и заблокировать данные 30-минутные слоты для онлайн-записи в клиентском приложении, исключая дабл-букинг).

## 2. Информационная модель системы (Сущности для ER-диаграммы)
1.  **Client (Клиент):** ID (PK), ФИО владельца, Номер телефона, Email, Статус блокировки.
2.  **Pet (Питомец):** ID (PK), ID_Client (FK), Кличка, Вид животного (кошка/собака), Порода, Дата рождения.
3.  **Doctor (Врач):** ID (PK), ФИО, Специализация (Терапевт, Хирург), График работы.
4.  **Slot (Временной слот):** ID (PK), ID_Doctor (FK), Дата, Время начала, Время окончания, Статус (Свободен/Занят).
5.  **Appointment (Запись):** ID (PK), ID_Client (FK), ID_Pet (FK), ID_Slot (FK), Дата создания, Статус записи.

## 3. Сопровождение: Разбор инцидента «Напоминание не пришло» (Методология RCA)
При поступлении тикета от пользователя аналитик проводит трехэтапный Root Cause Analysis:
1.  **Проверка статуса в БД:** По номеру телефона клиента выгружается ID записи (`Appointment ID`). Верифицируется, что запись успешна и не была отменена.
2.  **Проверка триггера планировщика:** Анализируется таблица `Notification Logs`. Проверяется, сформировал ли сервер фоновую задачу на отправку сообщения в планировщике задач (Cron) за 24 часа до приема. Если задачи нет — баг в коде фонового скрипта.
3.  **Анализ логов внешних интеграций:** Если запрос на СМС был сгенерирован, анализируется API-ответ от внешнего шлюза провайдера. Если шлюз вернул ошибку некорректного формата номера, аналитик фиксирует баг и ставит задачу на доработку фронтенд-валидации маски ввода телефона на этапе регистрации.
